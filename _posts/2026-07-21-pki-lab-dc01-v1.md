## Role

Domain Controller + DNS for the `lab.local` domain — the foundation every
other machine in the lab depends on for authentication and name resolution.

**Static config:** `192.168.10.1` / `255.255.255.0`, DNS `127.0.0.1`
(self-referential, standard for a DC running its own DNS role).

## Build Steps

1. VirtualBox VM created, Adapter 1 set to Internal Network (`LABNET`).
2. Static IP set inside Windows — `ncpa.cpl` → adapter Properties →
   TCP/IPv4 → `192.168.10.1` / `255.255.255.0`, DNS `127.0.0.1`.
3. Renamed computer to `DC01` (Settings → Rename this PC → restart).
4. Installed the **AD DS** role via Server Manager → Add Roles and
   Features.
5. Promoted to Domain Controller: new forest, domain `lab.local`, DNS
   Server option checked, DSRM password set, default NetBIOS name and
   paths accepted.
6. Verified post-promotion: DNS Simple/Recursive query tests passed,
   `lab.local` confirmed visible and correctly structured in Active
   Directory Users and Computers (ADUC).

```powershell
# Post-promotion DNS sanity check
Resolve-DnsName lab.local
nslookup lab.local
```

## Troubleshooting

**"Windows cannot find the Microsoft Software License Terms" during
setup** — hit on a separate VM early on (which was later renamed and
became CA01). Root cause: VirtualBox's Unattended Installation feature
builds a temporary `.viso` descriptor file, and in this case it
referenced a corrupted/incomplete or mismatched-path ISO, producing a
0-byte optical entry in the VM's Storage settings.

**Fix:** deleted the VM, redownloaded the ISO fresh from the official
[Microsoft Evaluation Center](https://www.microsoft.com/en-us/evalcenter/download-windows-server-2022),
recreated the VM with **"Skip Unattended Installation"** checked to
bypass `.viso` generation entirely, and completed a normal manual Setup
wizard.

**Clarified along the way:** "static IP" configuration happens *inside
Windows*, not inside VirtualBox — VirtualBox only defines the virtual
network switch (Internal Network), not host-level IP addressing. Worth
noting since it's an easy point of confusion early in a lab like this.
